# Крестики-нолики

Веб-приложение для игры в крестики-нолики на поле 3×3.

## Функциональные возможности

- Игра для двух пользователей.
- Поочередное выполнение ходов.
- Проверка занятости клеток.
- Автоматическое определение победителя.
- Тестирование игровой логики.

## Используемые технологии

- JavaScript
- HTML
- CSS
- Webpack
- Jest
- Git

## Установка и запуск

Установка зависимостей:

```bash
npm install
```

Запуск тестов:

```bash
npm test
```

Сборка проекта:

```bash
npm run build
```

## Система контроля версий

Ветка master содержит стабильную версию приложения.
Ветка dev используется для разработки и внесения изменений.
